# Lab01, прикладная статистика

Команда 13 (КТвД). ISU: 501564, 501235, 458829.

Тема работы: болиды и сближения астероидов с Землей. Данные берем из открытых каталогов NASA JPL, регистрация там не нужна.

## Что где лежит

- `lab01_fireballs.ipynb` основная часть, три случайные величины по болидам и генератор
- `lab01_asteroids.ipynb` доп. задание, две величины по сближениям астероидов
- `lab01_style.ipynb` общий стиль графиков
- `requirements.txt` библиотеки

## Данные

- болиды: https://ssd-api.jpl.nasa.gov/fireball.api
- сближения астероидов: https://ssd-api.jpl.nasa.gov/cad.api

Ноутбуки сами скачивают данные по этим ссылкам, руками ничего загружать не надо.

## Как запустить

В Google Colab: Файл, Открыть блокнот, вкладка GitHub, вставить ссылку на репозиторий и выбрать ноутбук.

Локально:

```
pip install -r requirements.txt
```

и открыть ноутбук в Jupyter или VS Code.

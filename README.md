## Что сделано в основном отчете

Спринт 1. Взяли каталог болидов NASA с 1994 года (1069 болидов) и разобрали три случайные величины. Для каждой показали что она случайная, сделали EDA, подобрали распределение, проверили гипотезу, взяли выборки с возвращением и без и посмотрели состоятельность оценок.

| величина | распределение | критерий | p-value |
|---|---|---|---|
| интервал между соседними болидами, дни (среднее 11.17) | экспоненциальное | Колмогорова-Смирнова | 0.184 |
| число болидов за месяц, шт (среднее 2.724) | Пуассона | хи-квадрат | 0.991 |
| синус широты точки падения | равномерное от -1 до 1 | Колмогорова-Смирнова | 0.184 |

Интервалы и число за месяц зависят друг от друга (корреляция Спирмена -0.739), широта ни от чего не зависит.

Спринт 2. Сделали генератор интервалов между болидами. Он состоит из своего датчика равномерных чисел (линейный конгруэнтный метод, Кнут, том 2) и метода обратной функции. Готовый датчик из numpy не используем. Проверили что сгенерированные числа похожи на настоящие: гистограммы рядом, таблица метрик, критерий Колмогорова-Смирнова для двух выборок (p-value 0.106), проверка через число болидов за месяц и 8 автотестов.

## Что сделано в доп. задании

- Отдельный датасет: сближения астероидов с Землей за 2015-2025 годы, 14 590 записей. Две величины: скорость сближения и число сближений за сутки. Для них показана случайность, сделан EDA и проверена связь между ними.
- Единый стиль графиков: одна ячейка стиля стоит в начале всех трех ноутбуков, те же цвета на странице генератора. Данные синие, теоретические кривые оранжевые, генератор фиолетовый.
- Оформление: оглавление со ссылками, номера разделов, свернутый код, формулы в LaTeX, единицы измерения на осях.
- Интерактивная страница в marimo: два ползунка, гистограмма с теоретической кривой, сравнение с теорией и лента времени.

## Данные

- болиды: https://ssd-api.jpl.nasa.gov/fireball.api
- сближения астероидов: https://ssd-api.jpl.nasa.gov/cad.api

Ноутбуки сами скачивают данные по этим ссылкам, руками ничего загружать не надо. В запросах стоят фиксированные даты, чтобы числа в отчете не менялись когда каталоги пополнятся.

Список литературы стоит в конце обоих отчетов.

## Как запустить локально

```
pip install -r requirements.txt
```

и открыть ноутбук в Jupyter или VS Code. Запускать ячейки надо по порядку сверху вниз, нужен интернет чтобы скачались данные.

## Страница с генератором

```
pip install marimo numpy matplotlib
marimo run generator_app.py
```

Откроется страница в браузере. Ползунками меняется среднее время между болидами и сколько болидов сгенерировать, графики сразу пересчитываются. Генератор тот же что в разделе 6 основного отчета.
